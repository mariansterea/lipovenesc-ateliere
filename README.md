# Lipovenesc Evenimente

Plugin WordPress pentru evenimentele din curtea Fermei Lipovenesc (Jurilovca): categorii cu reguli proprii, înscriere online în 3 pași, prețuri adult/copil, plată prin WooCommerce, bilete cu cod QR și check-in, listă de așteptare, emailuri de confirmare și reamintire, shortcode-uri pentru embed.

## Actualizări

Pluginul își verifică singur versiunile din acest repo (release-uri sau tag-uri `vX.Y.Z`). Update-ul apare în WordPress la Module, ca la orice plugin; linkul „Verifică update” forțează verificarea.

## Shortcode-uri

- `[lipovenesc_categorii]` cardurile mari de categorie
- `[lipovenesc_evenimente]` lista (opțiuni: `categorie`, `calendar="nu"`, `filtre="nu"`, `limit`, `titlu`, `layout="urmatoarele|arhiva"`)
- `[lipovenesc_eveniment id="123"]` un singur eveniment cu formular
